# Polina English Studio

Первая локальная версия учебной платформы Полины Каменских. Английский, 5–9 классы, подготовка к ОГЭ. Python 3.11+; сторонние библиотеки не нужны.

## Запуск

Дважды нажмите `start.bat`, затем откройте http://127.0.0.1:8088 . Или выполните `python server.py` из папки проекта. Пока сервер работает, окно нужно держать открытым.

На первом запуске создаются SQLite-база и случайные пароли в `data/first-login.txt`: `polina` — преподаватель, `alex` — демонстрационный ученик 9 класса. Пароли не встроены в сайт. Сохраните их в менеджере паролей и удалите текстовый файл. В кабинете «Аккаунт» можно сменить пароль.

## Обновление: курсы и учебный маршрут

Добавлены курсы, входная диагностика, работа над ошибками, личный словарь с карточками, конструктор пробников по разделам, прогресс по темам, приватные комментарии и календарь с уведомлениями в кабинете. Вход содержит только форму. Обновлена голубая/розовая палитра и добавлены иконки из локальной библиотеки.

Руководство: [docs/academy-guide.md](docs/academy-guide.md). Напоминания пока внутри кабинета; email и push не подключены. Контент пробников и критерии заполняет преподаватель.

## Что работает

- Раздельные кабинеты, выдача и сброс паролей, настройка часового пояса.
- Создание и редактирование заданий и материалов, архив с восстановлением.
- Назначение всему классу или конкретному ученику; сроки сдачи и индивидуальный таймер.
- История попыток; дополнительная попытка только по персональному разрешению преподавателя.
- Серверные черновики с защитой от конфликтов версий, восстановление на другом устройстве.
- Вопросы с выбором, короткий текст, сочинения, аудирование, запись и загрузка голосового ответа.
- Автоматическая и ручная проверка, баллы за вопрос, комментарий ученику.
- Конспекты, файлы, видео, ссылки и индивидуальное расписание с внешней видеовстречей.
- Адаптивный интерфейс. Первые материалы и тест — демонстрационные, не официальный банк ОГЭ.

Подробное руководство: [docs/learning-guide.md](docs/learning-guide.md). Важное ограничение: при истечении времени засчитывается последний серверный черновик; неотправленный локальный текст и незагруженная запись не учитываются.

## Проверка

`python test_academy.py` — 16 сценариев старых и новых функций. `python test_learning.py` — интеграционные проверки старых и новых сценариев на временной базе. `python check_learning_ui.py` — браузерная проверка через Playwright (необязательный инструмент разработки; для самого сайта Playwright не нужен). Проверяются вход, права доступа, сокрытие ответов, срок попытки, оценка, назначение, приватность файлов и уроков, сброс пароля и защита от запросов с другого сайта.

## Хранение и публикация

База: `data/studio.sqlite`; файлы: `uploads/`. Резервируйте обе папки вместе, при остановленном сервере. Не удаляйте их при обновлении. Текстовый файл с первыми паролями не публикуйте и не добавляйте в Git.

Сейчас это локальный пилот. Для доступа учеников из дома потребуется сервер, домен и HTTPS. Запуск за HTTPS-прокси: переменная `COOKIE_SECURE=1`, затем `python server.py --host 127.0.0.1 --port 8088`; прокси публикует только HTTP-приложение, не папку проекта. Python http.server подходит для локального пилота; перед публичной эксплуатацией перенести обработчики на ASGI/WSGI сервер, настроить бэкапы, журнал ошибок, лимиты загрузки и восстановление доступа. Не открывать порт 8088 напрямую в интернет.
