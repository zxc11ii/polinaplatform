# Новые разделы Polina English Studio

## Курсы по темам

Полина создаёт курс, выбирает класс или конкретного ученика и добавляет шаги. Шаг содержит объяснение, необязательный материал и практику. Ссылки можно выбирать только на материалы и задания, доступные всей аудитории курса. Курсы можно редактировать и архивировать.

Ученик отмечает изучение объяснения. Если у шага есть практика, шаг считается завершённым после изучения объяснения и проверенной попытки с результатом не ниже 60%. Курс без практики позволяет отметить прочтение. Стартовые курсы — редактируемые примеры, а не готовая полная учебная программа.

## Входная диагностика и учебный план

При создании задания выберите вид работы «Входная диагностика». У каждого вопроса укажите тему. Стандартные темы: времена, лексика, чтение, аудирование, письмо и говорение; можно ввести собственную. После проверки ученик видит результаты по темам и предварительный план: что повторить, а что закрепить. Перейти к курсам можно прямо из рекомендаций.

Стартовая короткая диагностика содержит авторские вопросы по трём темам. Она не определяет полный уровень владения языком и не является официальным экзаменом.

## Работа над ошибками

В очередь попадают вопросы с потерянными баллами из полностью проверенных работ. По кнопке «Потренироваться на ошибках» создаётся личное задание до шести вопросов. Если в доступных ученику заданиях есть другой вопрос той же темы, он подставляется вместо исходного. Иначе повторяется исходный вопрос; описание тренировки честно показывает число похожих заданий.

После успешного выполнения связанного вопроса исходная ошибка закрывается. Ручная перепроверка исходной работы также учитывается. Это подбор из заданий Полины, не генерация новых задач искусственным интеллектом. Чтобы тренировки были разнообразными, пополняйте банк вопросами с одинаковыми названиями тем.

## Слова и карточки

У каждого ученика личный словарь. Ученик может добавлять слова сам; Полина — выбирать ученика и пополнять его словарь. Можно указать перевод, пример и HTTPS-ссылку на аудиофайл.

Кнопка произношения проигрывает приложенный файл или использует английский голос браузера. Доступность и качество голоса зависят от устройства. Это не проверка произношения ученика.

В повторении сначала показывается слово, затем перевод. «Вспомнил» назначает следующее повторение через 1, 3, 7, 14 и 30 дней. «Ещё учу» возвращает карточку через 10 минут. Даты сохраняются на сервере; повторение доступно с другого устройства.

## Пробники ОГЭ

Вид работы «Пробник ОГЭ» включает конструктор разделов. Формат настройки: `Название | минуты`, каждый раздел с новой строки. Сумма времени разделов должна совпадать с общим временем задания. У каждого вопроса укажите раздел точно как в настройках. Разделы идут в заданном порядке. Сервер принимает изменения ответов только в пределах времени соответствующего раздела; прошлые разделы блокируются. Общий срок сдачи, если он раньше, сокращает попытку.

Для сочинений и голосовых вопросов можно задать критерии: `Название | максимум`, каждый с новой строки. Сумма максимумов должна совпадать с баллами вопроса. В ручной проверке Полина выставляет баллы отдельно по критериям. После полной проверки доступны результаты по разделам и сравнение работ в процентах.

Структуру и контент задаёт преподаватель. Реализация не маркирует произвольный набор вопросов как полный официальный вариант ОГЭ и не переводит баллы автоматически в государственную экзаменационную оценку. Актуальные документы ФИПИ: https://fipi.ru/oge/demoversii-specifikacii-kodifikatory . При просмотре 1 ноября 2026 на странице опубликованы проекты документов ОГЭ-2027. Полина должна сверить свою структуру и критерии с нужным учебным годом.

## Прогресс

Прогресс рассчитывается по полученным и возможным баллам последних пяти полностью проверенных работ с вопросами данной темы. Видно число работ, на которых основан результат. Непроверенные сочинения и записи не считаются окончательной оценкой. Для тем без результатов отображается «Ещё не проверяли».

## Комментарии к заданиям

Вопрос можно задать из карточки задания либо непосредственно под упражнением. Переписка разделяется по ученику, заданию и номеру вопроса. Другие ученики её не видят. Полина отвечает через раздел «Обсуждения»; ответ создаёт уведомление ученику. Во время обсуждения таймер задания продолжает идти.

## Календарь и напоминания

Календарь показывает уроки и сроки сдачи в часовом поясе аккаунта. Есть экспорт `.ics` для импорта в личный календарь. Это снимок расписания, не постоянная синхронизация.

Уведомления в кабинете создаются при приближении урока/срока (в пределах суток), наличии карточек к повторению, ответе на комментарий и ручной проверке. Непрочитанные можно отметить прочитанными. Уведомления формируются при обращении к кабинету; фоновой рассылки нет. Email, Telegram и push в закрытом браузере пока не подключены.

## Дизайн и иконки

На входе осталась только форма, без левого рекламного блока. Палитра: голубой, нежно-розовый, белый и тёмный текст. Иконки взяты из указанной пользователем локальной библиотеки Lucide; исходная папка не изменялась. На телефоне основные переходы вынесены вниз, остальные доступны в «Меню».

## Данные и проверка

Существующие аккаунты, пароли, материалы и попытки сохраняются. При первом обновлении добавляются три примера курсов, короткая диагностика, упражнения для повторения и по три стартовых слова существующим ученикам. Их можно изменить/архивировать.

`python test_academy.py` запускает 16 серверных сценариев на временной базе. `python check_academy_ui.py` проверяет интерфейс через Playwright, включая новый вход, курсы, диагностику, тренировку ошибок, словарь, приватный диалог, пробник, календарь и уведомления. Playwright нужен только для тестов, для работы сайта не нужен.
