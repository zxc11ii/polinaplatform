# Полине: как оставить замечания

1. Откройте [обзор экранов](https://zxc11ii.github.io/polinaplatform/). Это галерея текущего дизайна, не работающий кабинет.
2. Выберите раздел. Можно увеличить скриншот и сравнить телефон с компьютером.
3. Нажмите «Предложить правку»: откроется форма GitHub Issue. Для отправки нужен аккаунт GitHub.
4. Опишите «как сейчас» и «как хочется». Картинку с обведёнными местами можно перетащить прямо в текст замечания.
5. Лучше создавать отдельное замечание на каждую независимую правку. Список замечаний: [Issues](https://github.com/zxc11ii/polinaplatform/issues).

Если страница обзора ещё не открывается, проверьте [Actions](https://github.com/zxc11ii/polinaplatform/actions) и [настройки Pages](https://github.com/zxc11ii/polinaplatform/settings/pages): источником должен быть GitHub Actions. Скриншоты также доступны прямо в [docs/screenshots](docs/screenshots).

Для проверки самих функций запустите платформу по README. GitHub Pages не выполняет Python и не хранит ученические аккаунты.

База, пароли первого входа, загруженные файлы, логи и резервные копии исключены из репозитория. Скриншоты получены на временных демонстрационных данных.
